# What tools/build-windows.ps1 installs into its build virtualenv: the
# program's own Python requirements (README: numpy, PyQt6, pyaudio) plus
# Paramiko and PyInstaller. Pinned, so two builds of one version carry the
# same bytes; move them deliberately, and rebuild and re-run the suite under
# Windows when you do. Every one has a cp313 win_amd64 wheel (or is pure
# Python): nothing is compiled on the build machine, which has no compiler.
#
# The versions OpenHamShack NB/HAM's Windows build pins
# (~/openhamshack-nb/packaging/windows/requirements.txt), proven on the same VM;
# sharing them also lets the builds share pip's cache. PyAudio's Windows
# wheel carries PortAudio itself.

PyQt6-sip==13.13.0
PyAudio==0.2.14
# Pillow: the Teletext editor's (ohstxt) image import, PNG export and

# (libjpeg-turbo, libpng, zlib, libtiff, libwebp, OpenJPEG, Little CMS,
# FreeType, HarfBuzz...); their licences are all in its one LICENSE file.
