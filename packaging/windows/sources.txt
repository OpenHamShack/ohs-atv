# The Corresponding Source for the third-party GPL, LGPL and MPL code that
# OpenHamShack ATV's Windows installer (openhamshack-atv-<v>-setup.exe) carries, one
# tarball per line. It is published on the shared source site,
# https://source.brian-henderson.co.uk/#openhamshack-atv (/srv/source-site on
# shack; the format and procedure are docs/source-site.md in ~/openhamshack-nb),
# as the manifest openhamshack-atv:
#
#     python3 ~/openhamshack-nb/tools/source-site.py publish openhamshack-atv \
#         packaging/windows/sources.txt
#
# which fetches every file the site does not hold yet, checks every hash,
# and only then writes the manifest. A release that cannot publish this
# list must not publish the installer. THIRD-PARTY.txt (inside the
# installer) points at that section. (The manifest written on 06/10/2026
# for the .deb alone says the .deb bundles nothing; publishing this list
# replaces it.)
#
# Why host them rather than point upstream: GPL-3 section 6 and the LGPL
# let a distributor point elsewhere only while that elsewhere stays up, for
# as long as the binaries are offered (OpenHamShack DATV's sources.txt has the
# longer argument). A copy on our own server is the one we can vouch for.
#
# Fields, separated by "|" (spaces around them are trimmed):
#   file | sha256 | licence | installers that carry it | what it is the source of | url [fallback url ...]
# A line starting ">" is prose shown on the source site under the list.
#
# Most lines are OpenHamShack DATV's, for the same pinned binaries (Qt, PyQt6,
# Paramiko, libiio and its libraries, ADI's drivers, FFmpeg 9.0.2
# essentials); DATV's sources.txt says how each was identified. New here:
# libhackrf and the libusb it was built against (conda-forge's recipes name
# their source tarballs and hashes, read from each package's info/recipe on
# 08/10/2026). Not here: libmpv and its libraries (ATV does not carry it),
# ffplay (left out of the bundle), NB's WSJT-X and codec2.
#
# FFmpeg's open questions are DATV's and stay open here too, since this is
# the same binary: gyan.dev's cairo and libgme snapshots name no commit, and
# media-autobuild_suite's configuration for the build is not published.
